## Getting Ready for Development

<div className="fd-steps [&_h3]:fd-step">

### Work from the repository root

Open the theme repository in your editor and run the commands below from its root directory. The repository uses pnpm `10.29.3` and Node.js 20.x.

### Install dependencies

```bash
pnpm install --frozen-lockfile
```

This installs dependencies for the theme, the local Hexo demo site in `dev/site`, and the docs workspace.

### Enable theme development mode

For a Hexo site using the theme source, set `developer.enable` to `true` in its `_config.redefine.yml` file. The local demo site already enables this option in `dev/site/_config.redefine.yml`.

```yaml
developer:
  enable: true
```

### Start the local demo site

```bash
pnpm dev
```

This resets the demo site's generated state, links the current theme source into `dev/site/themes/redefine`, starts Hexo at `http://127.0.0.1:4000`, and watches Tailwind CSS. It does not rebuild browser JavaScript automatically.

</div>

## Build and Reset

Run these commands from the repository root:

```bash
pnpm clean
pnpm run build
pnpm run build:css
pnpm run build:js
pnpm run watch:css
```

- `pnpm clean` removes the demo site's generated `db.json` and `public/` directory.
- `pnpm run build` builds CSS and minifies browser JavaScript.
- `pnpm run build:css` builds `source/css/build/tailwind.css`.
- `pnpm run build:js` writes minified JavaScript and source maps under `source/js/build/`.
- `pnpm run watch:css` watches and rebuilds Tailwind CSS without starting Hexo.

Do not edit generated files directly. Theme build output lives in `source/css/build/` and `source/js/build/`; edit the source files instead.

## Project Layout

- `source/css/tailwind.source.css`: Tailwind CSS entry file.
- `source/css/`: Stylus and other theme styles.
- `source/js/`: Browser-side JavaScript source.
- `scripts/`: Hexo generation-time Node scripts.
- `layout/`: Hexo templates.
- `dev/site/`: Local demo-site configuration, posts, pages, and fixtures.

## Customizing the Theme

Edit `source/css/tailwind.source.css` for Tailwind utilities and theme CSS. For non-Tailwind styles, update the relevant files under `source/css/` and use the resulting classes in templates under `layout/`.

For more information, see the [official Tailwind CSS documentation](https://tailwindcss.com/docs).
