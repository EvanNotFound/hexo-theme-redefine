**Configuration item name: `home.sidebar.links`**

Refer to the [Navigation Bar](/home/navbar) for the writing format.

Leave it blank to hide.

Example configuration:

```yaml
home:
  sidebar:
    links:
      Archives: # Display name
        path: /archives # Path
        icon: fa-regular fa-archive # Icon, can be empty
      Tags: # Display name
        path: /tags # Path
        icon: fa-regular fa-tags # Icon, can be empty
      Test1:
        path: /test1
        icon: fa-regular fa-folder #
```

## Article Date Format

<Image
  src="https://assets.ohevan.com/img/6cc3c56cc613caa039ee8f2a2638f50e.png"

  width={2944}

/>

**Configuration item name: `home.article_date_format`**

|  Type  |                                 Optional values                                 | Default value |
| :----: | :-----------------------------------------------------------------------------: | :-----------: |
| String | `auto`, `relative`, `YYYY-MM-DD`, `YYYY-MM-DD HH:mm:ss`, `momentjs date format` |    `auto`     |

- `auto`: Automatic, select the date format based on the article date
- `relative`: Relative time, e.g., `1 hour ago`
- `YYYY-MM-DD`: Year-month-day, e.g., `2023-03-22`
- `YYYY-MM-DD HH:mm:ss`: Year-month-day hour:minute:second, e.g., `2023-03-22 12:00:00`
- `MMM D, YYYY`: Month day, year, e.g., `Mar 22, 2023`
- For more formats, please refer to [Moment.js](momentjs.com/docs/#/displaying/format/)

## Word Count and Reading Time

Display word count and estimated reading time beside the date on home-page
article cards. This feature requires the `hexo-wordcount` plugin:

```bash
npm install hexo-wordcount
```

### Switch

**Configuration Item: `home.word_count.enable`**

|  Type   | Possible Values | Default |
| :-----: | :-------------: | :-----: |
| Boolean | `true \| false` | `false` |

### Word Count

**Configuration Item: `home.word_count.count`**

|  Type   | Possible Values | Default |
| :-----: | :-------------: | :-----: |
| Boolean | `true \| false` | `true`  |

### Reading Time

**Configuration Item: `home.word_count.min2read`**

|  Type   | Possible Values | Default |
| :-----: | :-------------: | :-----: |
| Boolean | `true \| false` | `true`  |

### Display Quantity

**Configuration item name: `home.categories.limit`**

|  Type  | Optional values | Default value |
| :----: | :-------------: | :-----------: |
| Number |  0, 1, 2, ...   |       3       |

Categories are displayed as complete hierarchy paths, such as
`Parent › Child`. The limit counts paths rather than individual hierarchy
segments; use `0` to display every path.
