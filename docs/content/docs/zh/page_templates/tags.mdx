## 效果

`blur` 样式：

模糊程度根据标签的相对使用频率动态分配。文章数量相同的标签使用相同的模糊程度，使用最多的标签保持清晰。

## 配置


<div className="fd-steps [&_h3]:fd-step">

### 创建标签页面

在 Hexo 根目录执行以下命令：

```bash
hexo new page tags
```

然后，打开这个页面的 Markdown 文件（`source/tags/index.md`），编辑 Front Matter，添加 `template: tags`，即可。

```markdown filename="source/tags/index.md" {4}
---
title: 标签（你自定义的标题）
date: 2023/5/14 11:45:14
template: tags
---
```

### 导航栏添加标签页面

在 Redefine 主题配置文件 `_config.redefine.yml` 的 `navbar.links` 导航栏配置项里面添加标签页面。

```yaml filename="_config.redefine.yml" {3-5}
navbar:
    links:
        Tags: #取名随意
            icon: fa-solid fa-tags #图标
            path: /tags/ #链接
```

（放在二级菜单也可以）

### 修改标题（可选）

`title` 可以自由修改，但必须保留 `template: tags`，页面才会继续使用标签模版。

</div>

## 更改样式

在 Redefine 主题配置文件 `_config.redefine.yml` 的 `page_templates` 配置项里面更改 `tags_style`。

**配置项名称：`page_templates.tags_style`**

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 字符串 | `blur`、`cloud` | `blur` |
