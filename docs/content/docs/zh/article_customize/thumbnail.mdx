如果你想要对首页文章添加缩略图，如这样

![Screen Shot 2023-01-05 at 8.30.26 AM](https://assets.ohevan.com/img/9c2fa4a284882640e4c0da42cf2ebe5c.png)

## 配置流程

在对应文章的 `front-matter` 中增加

```yaml
thumbnail: "IMAGE_LINK"
```

## 示例

例如我上面提供的截图的配置

```markdown
---
title: 主题样式 Demo
date: 2022-12-30 19:07:05
tags: "demo"
thumbnail: "https://assets.ohevan.com/img/1f024c7274ee0740a3f811517381bd5d.png"
---
```
