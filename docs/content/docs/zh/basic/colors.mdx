## 主题色

**配置项名称：`colors.primary`**

请写 Hex 值，如 `#1890ff`。

主题色会影响到按钮、进度条、链接、选中等组件的颜色。

主题色背景上的文字和图标使用自动生成的 `--rd-primary-text`。主题会将 `colors.primary` 规范化为 Hex，并比较候选颜色 `#fff` 和 `#202124` 的 WCAG 对比度，自动选择与主题色对比度更强的候选颜色。
