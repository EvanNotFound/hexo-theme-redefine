## 自定义字体

### 中文字体开关

**配置项名称：`global.chinese.enable`**

|  类型  |     可选值      | 默认值  |
| :----: | :-------------: | :-----: |
| 布尔值 | `true \| false` | `false` |

**配置项名称：`global.chinese.family`**

|  类型  |      示例      |
| :----: | :------------: |
| 字符串 | `Noto Sans SC` |

## 阅读进度

### 顶部进度条

**配置项名称：`global.scroll_progress.bar`**

|  类型  |     可选值      | 默认值  |
| :----: | :-------------: | :-----: |
| 布尔值 | `true \| false` | `false` |

![image-20230321220020055](https://assets.ohevan.com/img/ccfb6d82577d527a5d5d5cf854ef3b86.png)

### 工具栏百分比

**配置项名称：`global.scroll_progress.percentage`**

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 布尔值 | `true \| false` | `true` |

启用后，工具栏百分比会随滚动在取整后的数值之间播放数字过渡动画。浏览器启用“减少动态效果”偏好时，数值会直接更新而不播放动画。顶部进度条仍是由 `global.scroll_progress.bar` 控制的独立连续指示器。

## 网站统计

**配置项名称：`global.website_counter`**

-   `url` 统计 API 地址, 默认为 `https://cn.vercount.one/js`.
-   `enable` 是否启用，填写 `true` 或 `false`，默认为 `true`。
-   `site_pv` 是否显示网站总访问量，填写 `true` 或 `false`，默认为 `true`。
-   `site_uv` 是否显示网站总访客数，填写 `true` 或 `false`，默认为 `true`。
-   `post_pv` 是否显示文章总访问量，填写 `true` 或 `false`，默认为 `true`。

## 单页应用体验

**配置项名称：`global.single_page`**

使用 Swup 库实现单页体验，推荐开启。其他详细信息请参考 [Swup](https://swup.js.org/)。

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 布尔值 | `true \| false` | `true` |

由于浏览器不会刷新，所以在 markdown 文件里面加入了自定义 javascript 的话，请在你的 `script` 标签中加入 `data-swup-reload-script` 属性，例如：

```html
<script data-swup-reload-script type="text/javascript">
	// 你的脚本
</script>
```

## 侧边工具栏

### 齿轮图标旋转

**配置项名称：`global.side_tools.gear_rotation`**

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 布尔值 | `true \| false` | `true` |

控制右下角工具栏中的齿轮图标是否持续旋转。

### 自动展开工具列表

**配置项名称：`global.side_tools.auto_expand`**

|  类型  |     可选值      | 默认值  |
| :----: | :-------------: | :-----: |
| 布尔值 | `true \| false` | `false` |

控制侧边工具列表是否在完整加载页面时默认展开。用户可以点击齿轮按钮切换显示状态，使用单页导航时会保留当前选择。
