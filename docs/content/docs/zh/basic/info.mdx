## 标题

**配置项名称：`info.title`**

站点标题，显示在网页标题栏。

![image-20230321211443153](https://assets.ohevan.com/img/d1004e6aa84fa74af8e951363e3a0517.png)

## 副标题

**配置项名称：`info.subtitle`**

站点副标题，访问首页时显示在站点标题后

![preview](https://assets.ohevan.com/img/f2c24a4f9d23ac4d7d5d896f207fdbc5.jpg)

## 作者

**配置项名称：`info.author`**

站点作者，显示为文章作者和站点底部。

![image-20230321211749089](https://assets.ohevan.com/img/09676886b1b4f8658c6d82bf9c4174dc.png)

## 站点地址

**配置项名称：`info.url`**

用于拼接文章，版权信息等链接，请正确填写，链接末尾不要加 `/`。
