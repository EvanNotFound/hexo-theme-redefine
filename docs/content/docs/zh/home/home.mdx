**配置项名称：`home.sidebar.links`**

写法格式请参考[导航栏](/home/navbar)。

留空则不显示。

示例配置：

```yaml
home:
  sidebar:
    links:
      Archives: # 显示的名称
        path: /archives # 路径
        icon: fa-regular fa-archive # 图标，可以为空
      Tags: # 显示的名称
        path: /tags # 路径
        icon: fa-regular fa-tags # 图标，可以为空
      Categories: # 显示的名称
        path: /categories # 路径
        icon: fa-regular fa-folder # 图标，可以为空
```

## 文章日期格式

<Image
  src="https://assets.ohevan.com/img/6cc3c56cc613caa039ee8f2a2638f50e.png"
  alt="image-20230322184235442"

**配置项名称：`home.article_date_format`**

|  类型  |                                    可选值                                    | 默认值 |
| :----: | :--------------------------------------------------------------------------: | :----: |
| 字符串 | `auto`, `relative`, `YYYY-MM-DD`, `YYYY-MM-DD HH:mm:ss`, `momentjs 日期格式` | `auto` |

- `auto`：自动，根据文章日期自动选择日期格式'
- `relative`：相对时间，如 `1 hour ago`
- `YYYY-MM-DD`：年月日，如 `2023-03-22`
- `YYYY-MM-DD HH:mm:ss`：年月日时分秒，如 `2023-03-22 12:00:00`
- `MMM D, YYYY`：月日年，如 `Mar 22, 2023`
- 更多格式请参考 [Moment.js](momentjs.com/docs/#/displaying/format/)

## 字数与阅读时间

在首页文章卡片的日期旁显示字数和预计阅读时间。此功能需要安装
`hexo-wordcount` 插件：

```bash
npm install hexo-wordcount
```

### 开关

**配置项名称：`home.word_count.enable`**

|  类型  |     可选值      | 默认值  |
| :----: | :-------------: | :-----: |
| 布尔值 | `true \| false` | `false` |

### 字数

**配置项名称：`home.word_count.count`**

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 布尔值 | `true \| false` | `true` |

### 阅读时间

**配置项名称：`home.word_count.min2read`**

|  类型  |     可选值      | 默认值 |
| :----: | :-------------: | :----: |
| 布尔值 | `true \| false` | `true` |

### 显示数量

**配置项名称：`home.categories.limit`**

| 类型 |    可选值    | 默认值 |
| :--: | :----------: | :----: |
| 数字 | 0, 1, 2, ... |   3    |

分类会按 `父分类 › 子分类` 这样的完整层级路径显示。此限制计算的是路径数量，而不是路径中的单个分类层级；设置为 `0` 时显示全部路径。
